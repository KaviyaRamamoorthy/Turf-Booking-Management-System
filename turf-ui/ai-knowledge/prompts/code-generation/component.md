# Prompt Library: Reusable Components

## Create Input Component with Validation

**Prompt**:  
"Create a reusable Input component in React using TypeScript, Tailwind CSS, and PrimeReact.  
Include custom validation using React Hook Form and show error messages."

**Expected Output**:
- Functional component
- Controlled input with validation
- Tailwind styling
- Proper TypeScript typing
