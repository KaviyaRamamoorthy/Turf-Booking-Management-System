# Prompt Library: Forms with React Hook Form

## Create a User Form

**Prompt**:  
"Build a user form in React + TypeScript with name, email, and password fields.  
Use PrimeReact inputs and React Hook Form with custom validation."

**Validation Rules**:
- Name: required
- Email: required, must contain '@'
- Password: min 6 chars
